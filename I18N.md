# BabiesIQ Cloud · Offline language system

The website uses **local, version-controlled dictionaries**. It does not call an Azure, Google, OpenAI or other machine-translation endpoint and never sends rendered account data, passwords or user text to a translator.

## Architecture
- `src/i18n/translations.js` is the shared English-source lookup and brand-protection layer.
- `src/i18n/locales/zh-TW.js` contains the longer Traditional Chinese interface and guidance copy. Keep `zh-TW` independent from Simplified Chinese `zh`.
- `src/i18n/locales/essentials.js` provides a curated common-navigation vocabulary for other languages that previously had no translations.
- `src/i18n/LocaleProvider.jsx` handles language preferences, react text and accessible HTML attributes, without translating secrets or elements marked `data-no-translate`.
- `src/i18n/config.js` detects browser language and region, including `zh-Hant-TW`; billing country is a **separate preference** and does not prove payer residence.

## Adding or reviewing copy
1. Use a plain English source string as the stable lookup key; translate through `useLocale().t('source')` for dynamic components. The DOM observer handles normal static public text.
2. Add a natural translation to the correct dictionary. Preserve brand and technical product names (`BabiesIQ Cloud`, `Railway`, `PayPal`, `Ubuntu`, etc.) and code/address literals.
3. Verify all warnings, error states, status badges, buttons, forms, mobile layouts, and locale changes. Never paraphrase away a data-loss or payment safety notice.
4. Run `npm run build` to build the website.

## Coverage and limitations
All 60 language choices have at least common interface vocabulary, but **this is not full paragraph-by-paragraph translation coverage** for all 60. Traditional Chinese and Hindi have more extensive wording; other locales fall back to English when a specific string has not been reviewed. Do not describe a missing translation as complete or machine-generated content as human-reviewed.

Do not change legal policies or payment rules merely to make translations sound polished: those require separate factual and legal review.
